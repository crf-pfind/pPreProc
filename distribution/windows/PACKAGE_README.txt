pPreProc for Windows
====================

1. Extract the ZIP archive.
2. Open PowerShell or Command Prompt in the extracted directory.
3. Run pPreProc with a RAW data path or a YAML configuration file:

   .\pPreProc.cmd "D:\data\sample.raw"
   .\pPreProc.cmd "D:\work\pParse2Plus.yaml"

For command-line options:

   .\pPreProc.cmd --help

Documentation: https://ppreproc.readthedocs.io/
Issues: https://github.com/crf-pfind/pPreProc/issues

The bin directory contains the files required by the application.

LICENSE.txt contains the application terms and required third-party notices.
