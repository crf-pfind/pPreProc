===============
Project support
===============

Use the channel that matches the request:

* reproducible defects: `GitHub Issues <https://github.com/crf-pfind/pPreProc/issues>`_;
* usage questions, integration help, and proposals:
  `GitHub Discussions <https://github.com/crf-pfind/pPreProc/discussions>`_;
* security vulnerabilities: follow the repository
  `security policy <https://github.com/crf-pfind/pPreProc/security/policy>`_.

A useful defect report includes the application and SDK versions, operating
system and architecture, installation method, input format, instrument or
vendor, acquisition mode, dataset size, exact command, minimal reproduction,
and relevant logs.

Do not attach restricted vendor data, credentials, licensed binaries, or
confidential logs.
