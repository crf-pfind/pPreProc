兼容性与验证
============

版本矩阵
========

=======================  ==========  =======  =======  ====================
应用程序                 Python SDK  C++ SDK  PFB/PFC  状态
=======================  ==========  =======  =======  ====================
2.5.2-rc.1               1.0.x       1.0.x    v1       Windows 候选发布版
=======================  ==========  =======  =======  ====================

SDK 1.x 可读取满足 v1 规范的带索引文件。读取器接受新增 PFC 列，现有 v1 字段
含义和单位保持稳定。不兼容的字节布局或字段语义变化必须使用新的格式版本。

历史 PFB 文件
=============

部分历史流式 PFB 文件不含 v1 尾部索引。SDK 会拒绝这些文件，不会通过扫描
整个文件将其作为 v1 索引文件读取。应使用兼容格式的写入程序，从保留的原始
数据重新生成 PFB/PFC 文件。

验证记录
========

合成测试样例在两种 SDK 实现中覆盖直接访问、扫描号定位、对应一级谱解析、
binary64 数组、提取离子流色谱图（XIC）、完整验证、CLI 输出和损坏数据处理。

另一次对当前带索引结果的完整解码验证了 14,455 张谱图、3,498,412 个谱峰和
11,477 条一级谱关联关系，未发现结构、字节边界或谱峰数不一致。该数据集不随
仓库发布，也不能替代对应用程序发布包本身的完整发布验证。
