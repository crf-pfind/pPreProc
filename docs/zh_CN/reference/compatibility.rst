============
兼容性与验证
============

版本矩阵
========

=======================  ==========  =======  =======  ==================
应用程序                 Python SDK  C++ SDK  PFB/PFC  状态
=======================  ==========  =======  =======  ==================
尚无公开版本             1.0.x       1.0.x    v1       当前公开接口
=======================  ==========  =======  =======  ==================

SDK 1.x 可读取满足 v1 规范的带索引文件。读取器接受新增 PFC 列，现有 v1 字段
含义和单位保持稳定。不兼容的字节布局或字段语义变化必须使用新的格式版本。

历史 PFB 文件
=============

部分历史流式 PFB 文件不含 v1 尾部索引。SDK 会拒绝这些文件，而不会通过全文件
扫描将其伪装成 v1 随机访问。应使用兼容写入器从保留的原始数据重新生成。

验证记录
========

合成测试数据在两种 SDK 实现中覆盖直接访问、扫描号定位、母谱解析、binary64
数组、XIC 提取、完整验证、CLI 输出和损坏数据处理。

另一次对当前带索引结果的完整解码验证了 14,455 张谱图、3,498,412 个峰和
11,477 条母谱关联，未发现结构、边界或峰数量不一致。该数据集不随仓库发布，
也不能替代未来应用程序压缩包本身的发布验证。
