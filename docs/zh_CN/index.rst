=============
pPreProc 文档
=============

pPreProc 是面向质谱数据预处理的 Windows 应用程序，并通过带索引的
PFB/PFC 接口支持下游快速访问。本文档介绍应用流程、公开 SDK 和文件格式约定。

.. note::

   pPreProc 应用程序以闭源二进制形式发布，核心源码不包含在本仓库中。
   Python/C++ PFB/PFC SDK、示例和接口规范以 BSD-3-Clause 许可证公开。
