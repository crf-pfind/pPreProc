=============
pPreProc 文档
=============

pPreProc 是用于质谱数据预处理的 Windows 应用程序，并通过带索引的
PFB/PFC 接口支持下游软件快速访问数据。本文档介绍应用程序工作流程、公开
SDK 和文件格式规范。

pPreProc 应用程序以 Windows 二进制软件包发布。公开仓库提供 PFB/PFC 格式
规范、参考 SDK、示例和文档，不包含应用程序核心源码及仪器厂商 SDK 源码。
