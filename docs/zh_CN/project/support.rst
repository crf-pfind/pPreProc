========
支持
========

请按问题类型选择渠道：

* 可复现缺陷：`GitHub Issues <https://github.com/crf-pfind/pPreProc/issues>`_；
* 使用问题、集成讨论和功能建议：
  `GitHub Discussions <https://github.com/crf-pfind/pPreProc/discussions>`_；
* 安全漏洞：按照仓库
  `安全策略 <https://github.com/crf-pfind/pPreProc/security/policy>`_ 私下报告。

有效的缺陷报告应包含应用程序与 SDK 版本、操作系统和架构、安装方式、输入
格式、仪器或厂商、采集模式、数据规模、完整命令、最小复现过程和相关日志。

请勿附加受限厂商数据、凭据、授权二进制或机密日志。
