==============
发布与版本管理
==============

版本体系
========

pPreProc 分别维护：

* 通过 GitHub Releases 发布的 Windows 应用程序版本；
* 由软件包和构建元数据声明的 Python 和 C++ SDK 版本；
* 由版本化规范目录表示的 PFB/PFC 格式版本。

各组件之间的兼容关系在兼容性矩阵中说明。版本号相同不表示它们共用一个发布
周期。

应用程序发布版
==============

应用程序发布版应包含可运行的 ZIP 软件包、校验和、面向用户的发行说明、应用
程序许可条款和第三方组件声明。GitHub 根据 Git 标签自动生成的源码压缩包不是
应用程序软件包。

发行说明按以下顺序组织：主要变化、安装或升级、兼容性、改进、修复、破坏性
变化、已知问题、校验和与文档链接。历史 ``v1.0.0`` 标签是 SDK 和文件格式
接口的首个公开基线，不是独立应用程序发布版。

首个独立软件包为面向 Windows x64 的 ``2.5.2-rc.1``。该候选发布版用于在稳定
版 ``2.5.2`` 发布前验证安装过程和各仪器厂商数据格式的工作流程。

文档版本
========

``latest`` 对应主分支。构建通过的稳定版软件标签可在 Read the Docs 中启用。
若存在与已安装应用程序或 SDK 对应的文档版本，应优先选择该版本。

支持周期
========

候选发布版不承诺长期支持。应用程序支持期限和停止维护日期将在首个稳定独立
发布版中公布。
