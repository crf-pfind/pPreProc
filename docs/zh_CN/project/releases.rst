==============
发布与版本管理
==============

独立版本
========

pPreProc 分别维护：

* 通过 GitHub Releases 发布的 Windows 应用程序版本；
* 由软件包和构建元数据声明的 Python/C++ SDK 版本；
* 由版本化规范目录表示的 PFB/PFC 格式版本。

各层面的兼容关系在兼容性矩阵中说明。版本号相同不表示它们共用一个发布周期。

应用程序 Release
================

公开应用程序 Release 应包含可运行 ZIP、校验和、面向用户的发行说明、应用程序
条款和第三方声明。Git tag 自动生成的源码压缩包不是应用程序软件包。

发行说明按以下顺序组织：主要变化、安装或升级、兼容性、改进、修复、破坏性
变化、已知问题、校验和与文档链接。历史 ``v1.0.0`` tag 是 SDK 和格式接口的
首个公开基线，不是独立应用程序 Release。

首个独立软件包为面向 Windows x64 的 ``2.5.2-rc.1``。该预发布版本用于在稳定
``2.5.2`` 发布前验证安装过程和各厂商数据格式工作流。

文档版本
========

``latest`` 对应主分支。通过构建的稳定软件 tag 可在 Read the Docs 中启用。
若存在与已安装应用程序或 SDK 对应的文档版本，应优先选择该版本。

支持周期
========

候选版本不承诺长期支持。应用程序支持期限和停止维护日期将在首个稳定独立
Release 中公布。
