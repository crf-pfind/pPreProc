====================
文档与软件发布边界
====================

项目包含两个用途不同的公开界面，不应将二者混为同一种 Release 产物。

在线文档
========

Read the Docs 是下列内容的规范维护入口：

* PFB/PFC 格式约定及兼容性边界；
* Python 和 C++ 接口参考；
* 命令行及集成示例；
* 架构、验证和应用使用说明。

文档由仓库源码持续构建，并随未来软件标签形成版本。API 页面和格式规范
不再作为第二种产品附加到 GitHub Release 中。

GitHub 软件 Release
===================

GitHub Release 专用于可运行的 pPreProc 应用软件包。公开的 Windows 软件包
必须包含统一的 pPreProc 入口、仅限必需的运行组件、适用的第三方声明和
许可证文本、校验和以及干净环境验证记录。

软件包不得暗示已编译的 pParse/pParse2+/pXtract 应用实现是开源代码，
也不得混入无关的 pFind 搜索、图形界面和结果报告程序。

版本管理
========

``latest`` 跟踪主分支文档。从下一个包含 Sphinx 配置的软件版本标签开始，
Read the Docs 可以同时提供稳定版和按版本固定的文档。历史 ``v1.0.0``
标签早于本站配置，应在 Read the Docs 中保持不激活，而不是改写已有标签。

引用
====

分析记录应注明 pPreProc 软件版本、平台、输入格式、命令或配置以及软件包
校验和。版本归档完成后，应同时引用对应的软件 DOI 和论文。
