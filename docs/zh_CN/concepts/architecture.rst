========
架构
========

pPreProc 包含三个功能阶段：

.. code-block:: text

   厂商数据 -> pXtract 提取 -> PFB/PFC -> pParse2+ -> 下游检索
                                |
                                +------> Python/C++ SDK

``pXtract`` 负责面向仪器的数据提取；PFB/PFC 通过尾部索引保存谱图及选定的
元数据；``pParse2+`` 在既有 pParse2 前体结果基础上，补充来自 pXtract 输出和
针对性枚举的证据，并将多路结果统一整理后提供给下游流程。

公开边界
========

Windows 应用程序和 PFB/PFC 开发者接口相互关联，但属于不同的公开层面：

* 应用程序是闭源的 Windows 二进制发行包；
* PFB/PFC 是公开、带版本的存储约定；
* Python 和 C++ SDK 是公开的参考实现；
* 对未实现 PFB/PFC 的软件，MGF 仍可作为交换路径。

公共仓库不包含应用程序核心源码或厂商 SDK 实现，而是提供产品下载、文档、
集成、测试和问题反馈所需的公开材料。
