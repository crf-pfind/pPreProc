==================
数据精度与保留范围
==================

谱峰数组
========

PFB 将导出的每个 m/z 和强度值以小端序 IEEE 754 binary64 保存，不对这些
数值进行十进制舍入、量化或有损压缩。

元数据
======

PFC 保留已验证的预处理和索引访问流程所需的元数据。命名字段包括谱图标识与
关联、保留时间、仪器信息、活化方式与母离子属性、谱峰数和 PFB 字节边界。

PFC 不保存各仪器厂商 API 提供的全部属性。

==============================  ========================================
数据                            v1 保证
==============================  ========================================
导出的 m/z 和强度               以 binary64 保存，不产生格式转换造成的数值损失
PFC 核心命名字段                按 v1 规范保留
新增可选 PFC 列                 兼容读取器可接受
全部厂商原生元数据              不保证
厂商原始标识符字符串            v1 没有专门字段保证
离子淌度坐标                    v1 核心字段不保证
==============================  ========================================

当工作流程需要 PFB/PFC v1 未涵盖的属性时，应保留并查询仪器厂商原始数据。
读取器不应根据谱图顺序或其他字段推断未记录的值。
