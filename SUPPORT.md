# Support

Choose the channel that matches the request.

| Request | Channel |
|---|---|
| Reproducible application or SDK defect | [GitHub Issues](https://github.com/crf-pfind/pPreProc/issues) |
| Usage question or integration discussion | [GitHub Discussions](https://github.com/crf-pfind/pPreProc/discussions) |
| Feature proposal | [GitHub Discussions](https://github.com/crf-pfind/pPreProc/discussions) |
| Documentation defect | [Documentation issue](https://github.com/crf-pfind/pPreProc/issues/new?template=documentation.yml) |
| Security vulnerability | [Private security report](SECURITY.md) |

Before reporting a defect, record the pPreProc application version, SDK
version, operating system and architecture, installation method, input format,
instrument or vendor, acquisition mode, dataset size, exact command, and the
smallest permitted reproduction.

Do not attach proprietary vendor data unless you have explicit permission to
share it.
