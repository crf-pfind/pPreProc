# Security policy

Report suspected vulnerabilities privately to `chihao@ict.ac.cn`. Do not open
a public Issue for an undisclosed vulnerability.

Include the affected application or SDK version, operating system, a minimal
reproduction, and the expected impact. Remove credentials, personal data, and
restricted raw data from the report.

Security fixes are evaluated for the latest supported release of the affected
component. Public disclosure is coordinated after a fix or mitigation is
available.
